# 宿傩 AI 对话

从角色右键菜单打开“AI 对话”，在独立原生窗口中聊天。先在“桌宠设置 → AI 对话”保存自己的 DeepSeek API Key。缺失或无效 Key 时，聊天窗口会显示设置入口；修复后由你手动发送或重试。

Enter 发送，Shift + Enter 换行；中文输入法选字时的 Enter 不发送。回复逐段显示，首字到来前显示“正在生成”，此时也能停止。生成期间可以编辑下一条草稿，当前回复结束后手动发送。

点击“停止”或关闭聊天窗口，会立即停止界面接收新内容，保留已收到的正文并标记“未完成”。重开会激活同一窗口和当前对话，关闭聊天不会退出桌宠。界面停止不保证 DeepSeek 服务端立即停止计算或计费。

未完成回复下方可手动“重试”，这会重新请求原问题并替换未完成回复，可能再次消耗 API 额度；原问题不会重复进入聊天记录，被替换的回复不会进入重试上下文。直接继续追问则可以沿用未完成正文。余额不足、限流、服务繁忙、断网、超时、空正文和断流分别提示原因，不自动重发。

请求固定使用 `deepseek-flash` 并关闭思考，只展示和传递正文。每次启动请求时取得当前 Key 快照；后续保存或清除 Key 影响后续请求，不会撤回已发送的请求。

侧栏可新建、切换和删除对话；窄窗口可用顶部“◫”展开侧栏。新建或切换会停止当前生成，部分回复保留在原会话并标记未完成；删除前需要确认，只删除当前会话的本机记录。删除正在生成的会话也会停止生成。

对话完整记录保存在本机，重启后可继续；向模型发送的历史最多 40 条、24,000 字符，system 和本轮问题另外加入，较早的本机消息不因请求裁剪而丢失，也不会自动总结。会话保存创建时作者原文、补充要求及版本快照；作者版本更新后，已有会话继续用旧版，新建会话使用新版。没有使用者编辑人设入口，也不加入默认人设、时间或记忆。

正式启动时，记录目录为 Windows 当前用户的 `QStandardPaths.AppLocalDataLocation/chat/sessions`，通常位于 `%LOCALAPPDATA%/skip-pet/sukuna-pet/chat/sessions`。每个会话独立保存为版本化 JSON，包含完整消息、时间和请求关联；凭据仍独立放在 Windows 安全存储。聊天记录包含私人内容，请自行管理本机文件的访问权限。程序不导入或修改参考桌宠的数据。

回复生成时持续提交本机快照，由一个后台线程串行、原子保存；尚未写入磁盘的内容显示“尚未保存”。写盘失败时可点击“重试保存记录”；最后一次成功保存的文件保持完整。关闭聊天或退出桌宠会等待保存，磁盘仍忙时界面继续响应；失败或等待超过 3 秒会提供“重试保存”“取消关闭”“确认关闭”，确认关闭可能丢失尚未写入的内容。确认关闭不会删除仍在内存中的可见内容，当前进程重新打开仍可重试保存；进程异常终止可能丢失最后尚未落盘的片段。

重启时，“生成中”记录一律恢复为“未完成”，可继续追问或手动重试。损坏记录会报告错误并创建带时间戳的 `.corrupt-...` 备份，原文件保留；备份失败也保留原文件。无法读取或未知版本的文件会提示并保留，不覆盖为空对话；有效的其他会话仍可使用。

AI 生成不进入任务状态气泡，也不触发任务联动跳动。#51 完成了源码版的多会话与恢复；完整视觉集成和安装版作者试聊仍由 #52–#53 承接，本票源码改动尚未包含在已有安装包中。
