# 桌宠设置

从角色右键菜单选择“桌宠设置”。重复打开会激活同一窗口；关闭设置或按 Escape 不退出桌宠。

- **桌宠**：点击跳动、持续跳动、任务联动，以及小 188px / 中 271px / 大 320px。修改立即保存，与右键快捷项同步；保存失败保留原值并提示。
- **任务联动**：查看已有 DeepSeek Harness 接入、启停及检查修复。首次启用沿用原来的预检和安装范围确认；维护时按钮禁用，失败沿用已有提示与诊断。未增加宿主接入范围。
- **AI 对话**：配置 DeepSeek API Key。输入是草稿，点击“保存”后才使用；空白不覆盖当前值，“取消修改”和关窗放弃草稿。保存不发送请求。
- **关于**：显示由当前源码/安装元数据读取的实际版本和开源署名。

Key 保存在当前 Windows 用户的凭据管理器中，条目命名空间为 `skip-pet/sukuna-pet/deepseek-api-key`，不写入 mode.json 或聊天记录，不读取 dsh-pet 的凭据。安全存储不可用时，Key 只用于本次运行，界面提示重启需要重新输入。

“清除密钥”立即清空当前 Key、输入草稿和撤销历史，并尝试删除安全存储。删除失败时会明确提示旧凭据可能仍留在存储中，当前进程不重新载入它；可再次点击清除。这项操作不会在 DeepSeek 服务端撤销 Key，也不能撤回已发送的请求。

“测试连接”经确认后发送一次可能计费的短请求，使用输入框中的待测 Key，为空则使用当前 Key。固定 `deepseek-flash`、关闭思考。测试不保存 Key，不写聊天记录，不自动重试；结果仅说明这一次请求，Key 已保存也不表示持续在线。

本实现属于 #49。聊天界面、会话记录、完整视觉集成和冻结安装版作者试聊由 #50–#53 承接；已有 0.3.0 安装包尚未包含本次源码改动。
