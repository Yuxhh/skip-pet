## 0.2.1 历史基线

交付日期：2026-10-25。安装包包含 V5 头眼阶段推进、220ms 点击回弹、约 450ms 段间等待、三档大小、动态轮廓与贴边，以及模式/大小记忆。无诊断控制窗、宿主联动或联网依赖。

本机为 Windows 11 x64、单屏 1920×1080、100% 缩放（DPR 1.0）。源码自动化、独立目录运行/重建和本机安装操作是不同层次的证据。精确逐帧时序由冻结轨迹回归检查；本机观感与操作不能构成跨机器帧率承诺。

0.2.1 修复快速连点时头发和衣服边缘的瞬态残影。独立进程连续采集运动中的桌面像素，检查每张画面都对应完整绘制帧；显示与透明命中使用同一整帧 alpha，不再逐帧设置原生裁剪。详细结果及重现命令见源码中的 `docs/verification/issue-29/README.md`。
