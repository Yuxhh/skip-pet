# 宿傩桌宠 0.4.0 候选验收范围

2026-10-27（Asia/Shanghai）。本候选承接 #49–#52 的 AI 对话、会话记录、凭据、设置与原生界面。提示词版本 `sukuna-2026-10-27-v1`；固定 `deepseek-flash`、关闭思考。版本与冻结模块逐文件摘要见 build-report.json；Setup、源码 ZIP 与报告的哈希见 SHA256SUMS.txt。

本候选等待 #53 作者自备 Key 的安装版三组真实试聊。作者尚未确认语气，不能把连接测试、system 内容或自动化通过当作作者验收。按同目录 `试聊验收.md` 操作，反馈脱敏输入、原回复和通过/差异结论。人工通过后继续交付收尾；任何影响已验行为的代码或打包变化都必须重验。

源码行为和原生视觉的既有证据见源码包 `docs/verification/issue-49` 至 `issue-52`；本次候选验证记录在 `docs/verification/issue-53`。只按该记录的实际结果判定，不把本机安装、隔离数据或合成请求当作干净 Windows、真实计费服务或作者试聊。

安装验证入口为 `SukunaPet.exe --verify-installation <不存在的新目录>`，在真实冻结运行时验证独立测试目标的 Windows 凭据读写/删除、跨进程读取、真实适配器拒绝过长值后的仅内存降级、合成会话与人设重启恢复、窗口复用/关闭、兼容旧偏好及未知字段、Windows TLS CA 可用性。入口不会访问产品凭据目标、个人聊天或宿主 profile，也不会调用计费接口。`result.json` 记录结果，失败时非零退出并记录异常类型。它不验证服务商真实回复或所有安全存储策略故障。

当前单显示器 Windows 11 x64；真实多屏、负坐标屏、混合 DPI 切屏、硬件插拔及无 Python 的干净 Windows 仍未实测。既有任务桥的日常范围及未知归属限制沿用 #41/#42，未扩展支持矩阵。Node/pnpm 是接入维护的外部前置，不是角色或聊天的运行依赖。

程序不含开发 Key、个人会话、参考程序资料或原视频。会话与偏好保存在自己的用户数据目录，Key 保存在当前用户 Windows 凭据管理器；卸载保留这些用户数据。Qt/Python 等第三方许可及 dsh-pet MIT 全文随包提供，含 Copyright (c) 2026 Merzlin。Setup 未签名，尚未公开发布。

0.3.0 的历史用户验收与硬件边界见源码包 `docs/verification/issue-42/README.md`；其结论不代表本候选 AI 功能验收。
