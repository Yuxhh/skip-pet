# 宿傩桌宠 0.2.1（V5）验收范围

交付日期：2026-10-25。安装包包含 V5 头眼阶段推进、220ms 点击回弹、约 450ms 段间等待、三档大小、动态轮廓与贴边，以及模式/大小记忆。无诊断控制窗、宿主联动或联网依赖。

本机为 Windows 11 x64、单屏 1920×1080、100% 缩放（DPR 1.0）。源码自动化、独立目录运行/重建和本机安装操作是不同层次的证据。精确逐帧时序由冻结轨迹回归检查；本机观感与操作不能构成跨机器帧率承诺。

0.2.1 修复快速连点时头发和衣服边缘的瞬态残影。独立进程连续采集运动中的桌面像素，检查每张画面都对应完整绘制帧；显示与透明命中使用同一整帧 alpha，不再逐帧设置原生裁剪。详细结果及重现命令见源码中的 `docs/verification/issue-29/README.md`。

以下项目仍待验，不能以合成屏幕/DPR、单屏或历史原型结果替代：

- 真实双屏双向拖动、负坐标屏及桌面间隙。
- 100% 与 125%/150%/200% 混合 DPI 双向切换，含播放中拖动、各屏边缘释放与三档缩放。
- 任务栏/工作区改变、屏幕几何或连接变化及屏幕移除。
- 无 Python 开发环境的干净 Windows 10/11 安装到卸载。
- 用户对本次安装产物完整连续动作、脸型、头颈接缝及衣领遮挡的最终视觉认可。

完整的本轮实际结果、性能测量、环境、哈希与证据位于随源码交付的 `docs/verification/issue-28/README.md`。硬件逐项条件沿用 `docs/verification/issue-27/installer-handoff.md`。未完成项保持待验，本版不宣称全部硬件验收通过。安装器未作代码签名。
