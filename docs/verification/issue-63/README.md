# Diamond Cut Diamond 音乐跳动 · 0.4.3 本地候选

2026-10-28（Asia/Shanghai）。对应任务：[新增 Diamond Cut Diamond 音乐跳动入口](https://github.com/Yuxhh/skip-pet/issues/63)。

## 确认的行为

右键菜单在“任务联动”下方增加“音乐跳动”。只使用用户提供视频的音轨，截取 0–14 秒，终点依据用户“大概在14秒”的说明。片段循环，总计约 15 秒后音乐和动作停止，保持静止，不恢复先前持续/任务自动跳动。再点菜单或角色从头开始；播放中再次点击提前停止，拖动不播放。重启记住音乐模式但不自动播放。

约 128 BPM 的节拍位置由这段音轨低频起音拟合。动作使用 QAudioSink 的 processedUSecs 采样时钟；重复的 PCM 数据在同一播放缓冲区连续送出，避免播放器循环重载和渲染时钟漂移。音频仅为随包 WAV，运行不需要原视频或识别模型；10 ms 会话尾部渐弱避免硬切噪声。

参考 dsh-pet 的 `pet/window_alerts.py:check_music_sing`，但本需求主动播放固定片段，停止后保持静止，故不采用外部音乐检测及恢复普通动画的行为。
