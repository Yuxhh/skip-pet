## 本机实际安装与 OS 输入

环境：Windows 11 x64 10.0.26200、G24H1 单屏 1920×1080、工作区 1920×1032、DPR 1.0。升级安装调用本次 `Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /TASKS=desktopicon`，返回 0；显式指定既有当前用户路径 `%LOCALAPPDATA%\Programs\SukunaPet`。HKCU 卸载条目版本 0.2.0，既有仅含 `{"mode":"click"}` 的偏好字节保持不变。

- 实际从新开始菜单快捷方式启动，进程来自安装目录；初始静止且默认 320px。加载的 Python、Qt、shiboken 均来自安装目录；ICU 来自 Windows System32，见 [modules.json](installed/modules.json)。目标机仍有 Python，故不据此声称干净 Windows 已验收。
- 使用 computer-use 的真实 OS 鼠标单击、三连点、右键菜单与短距离拖动。拖动使窗口从 `(1559,679)` 移到 `(1589,709)`；释放后仍显示初始姿态。更长拖动两次因终点不是目标可见区域而被工具拒绝，首次越出窗口边界也未执行；均不计为拖动或四边通过。
- 人物区域 `WindowFromPoint` 命中本进程，透明点命中真实下层 Receiver 窗口。实际点击人物画布内的透明留白，下层计数 **0→1**，人物仍保持视线 1；另一次远处下层点击使计数到 2。下层前置时桌宠仍可见，原生置顶标志为真。
- 选择持续模式，实际设置为 `always`，多次截图可见姿态改变；持续时三连点仍可执行。切回点击模式后保持，设置为 `click`。精确 220/240/450ms 与动作中切换由冻结轨迹和窗口自动化覆盖，静态截图不替代逐帧时序验证。
- 菜单三档均实际选择：193×188、278×271、328×320，偏好同步更新。右键退出后进程消失，从**可选桌面快捷方式**启动新进程，188px 与持续模式均恢复且菜单勾选正确。再切回点击并恢复 320px。
- 正常调用该安装器生成的 `unins000.exe` 卸载，返回 0，程序目录、HKCU 卸载条目、开始菜单、桌面快捷方式与进程全部消失，偏好字节保留。见 [uninstall.json](installed/uninstall.json)。没有手动清理文件或注册表来制造通过。
- 同一安装器重装返回 0，重新建立入口，从开始菜单恢复启动；161 个安装文件与构建报告逐个哈希一致、0 个不匹配，见 [reinstall.json](installed/reinstall.json)。

真实 OS 操作在安装进程执行；辅助 Receiver 和只读观察脚本是外部验证工具，**未随安装加入诊断窗口**。观察脚本见 [observe_installed.py](observe_installed.py)，从源码根目录使用验证 Python 执行；它只读取窗口区域、OS 命中与桌面图像，不注入输入。原始安装/卸载日志保留在 `.scratch/issue28/`。

随后在左上角选择持续播放，外部只读工具采样 120 次：窗口位置随轮廓变化，118 个样本完整贴齐，2 个窗口/区域组合超出工作区。保留原始 [top-left-continuous.json](installed/top-left-continuous.json)。进一步双次读取窗口与区域，120 个样本的双次结果均一致，但仍有 5 个组合不完整，见 [top-left-continuous-double-read.json](installed/top-left-continuous-double-read.json)。双次读取仍跨多个 Win32 调用，不能提供与 Qt 一次更新/Windows 合成帧相同的原子快照；当前证据既不能把异常全部归因于采样，也不能据此证明稳定显示帧发生裁切。**贴边播放的可见帧与命中一致性仍须进一步复核，未计通过。** 只读工具见 [sample_installed_edges.py](sample_installed_edges.py)，没有为隐藏异常而修改生产代码。

负坐标运动窗口弹出菜单的截图标识连续失效，188px 贴边缩放选择未执行成功，不计为贴边缩放通过；原先普通位置的三档选择结果仍有效。结束补验后用 Alt+F4 关闭本会话，经既有 `save_mode` 接口恢复原 click（保留320），再从开始菜单启动；这次偏好状态恢复不是额外GUI选择模式通过证据。补充记录收紧验收范围，不能扩大为全部安装版贴边通过。

## 性能

工具 `tools/measure_runtime.py` 在真实 Windows 源码进程、328×320、DPR 1.0，以公开 Qt 点击和真实时间采样，启用 cProfile；测量包含分析器、8ms 观察采样和其他本机负载。最终结果见 [performance.json](performance.json)。此前沙箱测量约 22.6ms/帧；最终交互桌面测量如下，不能混成同一次结果。

| 场景 | 采样时长 | 栅格化/区域重建次数 | 平均绘制 | 平均区域重建 |
| --- | --- | --- | --- | --- |
| 首次静止 | 1.20s | 0 / 0 | 无 | 无 |
| 一次点击含停留 | 1.41s | 7 / 7 | 29.89ms | 3.58ms |
| 前 600ms 连点，随后停留 | 1.81s | 23 / 23 | 27.38ms | 3.17ms |
| 持续播放 | 4.50s | 53 / 53 | 27.73ms | 3.35ms |
| 自然收尾后静止 | 1.20s | 0 / 0 | 无 | 无 |

应用动作精度和采样规则未改变，静止不重复栅格化。次数不等于瞬时播放帧率，含段间等待。另在**实际安装进程**各采样 3s，持续播放 CPU 1.609375s（约占单核 53.6%）、工作集 113,483,776 字节；点击静止 CPU 0.09375s（约单核 3.1%）、工作集 100,384,768 字节，见 `installed/cpu-*.json`。静止仍有 Qt 定时适配与原生事件，不宣称 CPU 为零。当前单机/短采样没有跨机器稳定帧率保证。
