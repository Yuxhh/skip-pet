# #26 动态贴边与贴边缩放

日期：2026-10-25。正式源码 `PetWindow`，本机 Windows、Python 3.14.4、PySide6 6.12.0；G24H1，1920×1080，工作区 1920×1032，DPR 1.0。未更新安装器，未修改或关闭父规格 #22；跨屏和真实混合 DPI 由后续票承担。

## 行为与实现

拖动限位沿用当前最终帧生成的 alpha 区域包围盒，透明画布可以越出工作区。窗口记录实际接触的水平及垂直边。每张新帧更新图像和区域后，按当前轮廓重新对齐所贴边，再限制人物完整可见。没有使用最大动作并集，也没有改变固定运动视口、素材或动作参数。

拖动重新计算实际接触；离开一条边只解除该方向。未贴边方向保持窗口锚点。缩放保留原有底部/中心锚点，并优先对齐所贴边，立即更新图像和命中。只保存既有大小/模式，不保存贴边和位置。

按下期间单独累计每帧轮廓补偿造成的窗口位移，在下一条拖动或释放事件中沿用，避免应用按下时的固定拖动原点覆盖最新补偿。系统阈值、全局坐标和原生鼠标捕获继续由已有入口处理；捕获中断、隐藏、菜单和缩放清理未完成手势。

开始时已有 #25 播放调度及其他规划改动。本票保留这些工作，只修改桌面贴边适配及本票测试、工具和说明。

## 自动化

测试边界为 #22 已确认的应用点击/可控时间/只读视图，以及 Qt 公开鼠标事件、菜单、窗口几何、最终图像与区域。没有测试私有方法或绘制次数。

`tests/test_edges.py` 新增 41 个测试：

- 三档 × 四边/四角/居中，共 27 种布局；四次 Qt 点击循环到四个终点，每次采样 22ms 连续帧、110ms 峰值、220ms 恢复及最终停留。逐帧检查接触与完整可见，未贴边方向和居中位置不漂移。
- 按住期间轮廓变化后，继续移动和在同一光标位置释放，窗口不会跳回旧原点；释放不推进阶段或重启回弹。
- 从左上角分别拖离水平、垂直和两条边，只有仍接触的方向继续补偿。
- 八种贴边布局在回弹峰值切换 188→271→320→271→188，公开图像逐像素匹配命中区域，阶段不变。新实例恢复大小及默认摆放，偏好仅含 size。
- 贴边轮廓补偿中丢失捕获或隐藏，随后释放不变成点击。

TDD 首先复现顶部回弹峰值离边 32px；实现逐帧补偿后通过。随后复现按住期间补偿后，下一次拖动将窗口从 y=-73 拉回 y=-67；累计补偿后通过。偏好测试曾错误预期默认 click 会自动写入，已纠正为原有只写 size 的行为，未为测试改变产品规则。

完整回归：**178 passed in 106.69s**，见 [pytest.txt](pytest.txt)。严格类型检查：**6 个源文件无错误**，见 [mypy.txt](mypy.txt)。旧动作、回弹、拖动、多屏几何夹具、大小、模式和设置回归均保留；offscreen 测试不冒充物理硬件验收。

## 真实 Windows 操作

`tools/verify_edges_native.py` 默认显示正式桌宠与下层 receiver，只使用本目录的隔离偏好。通过 computer-use 真实 OS 鼠标操作：四角拖动、持续播放、左/上/下/右边、离边自由摆放、320→188→271 菜单缩放、切回点击及菜单退出。输入和最终结果分别见 [os-input-trace.jsonl.gz](os-input-trace.jsonl.gz)、[os-summary.json](os-summary.json)、[os-result.json](os-result.json)。

41,161 个观察样本全部完整可见；326 个样本记录到原生 `GetCapture` 为桌宠。四角均有四阶段和回弹峰值样本。188px 左边/上边、271px 上边/下边/右边同样覆盖四阶段峰值。非贴边轴保持固定，补偿轴随轮廓变化。真实点击透明位置 `(20,80)`，receiver 从 0 到 1，角色阶段保持 3，`WindowFromPoint` 返回下层窗口。点击模式的拖动前后阶段及回弹相同；持续模式下阶段仍会由自动调度推进。最终经真实菜单退出：exit_code=0、closed=true，隔离偏好为 click/271。

OS 工具最初直接在观察计时器内抓图，可能抓到 Qt 更新图像/区域之后、Windows 分层缓冲上传之前的瞬态旧轮廓。该批快速截图没有用作稳定外观对照；原始图保留在本地 `.scratch/issue26-transient-captures/`。几何与 OS 输入原始日志保留。随后以固定时间重新采集下面的像素证据，无需修改生产绘制来掩盖截屏时序。

## 稳定原生像素

`--capture` 使用公开 Qt 鼠标事件和应用虚拟时间，明确区别于真实 OS 输入。每帧固定虚拟时间后等待 60ms，让 Qt 绘制及 Windows 分层缓冲完成上传，再取真实桌面像素。下层验证背景临时置顶，桌宠在其上方；不改变系统设置。

三档 × 八种贴边 × 四阶段 × 峰值/停留，共 **192 个样本**。每个检查当前区域完整可见及所贴边接触，并将真实桌面图像与最终帧在下层背景上的合成逐像素比较。所有样本 RGB 通道差超过 3 的像素数为 **0**；结果见 [native-capture.json](native-capture.json)。`settled-*.png` 为每档每种贴边的第一阶段峰值裁图，涵盖屏幕内的完整画布区域。它们是本轮正式生产窗口的真实桌面像素，不是离线 renderer 输出。
