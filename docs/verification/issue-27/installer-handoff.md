每项应记录安装产物 SHA-256、源码提交、Windows/Qt 版本、屏幕名称、几何位置、各屏工作区与缩放；保存输入操作说明、前后截图、原生日志及人工结论。相邻屏幕应另验普通位置的稳定锚点、离边解除、当前动态透明命中与下层真实应用点击。

可运行 `tools/verify_screens_native.py --output <新的证据目录> --seconds 300`，打开使用隔离偏好的正式源码窗口，手动执行操作并记录屏幕事件及当前画面 DPR/几何/姿态。此工具不修改系统显示配置，不自动判定场景通过；不能把源码工具日志描述为安装产物验收。安装版应另记录真实进程路径与安装包哈希，结合 OS 操作证据逐项填写结论。
