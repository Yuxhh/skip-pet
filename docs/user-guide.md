# 宿傩桌宠 0.1.0

适用于 Windows 10 1809 及更新版本、Windows 11 x64。双击 Setup.exe，按向导安装；默认安装到当前用户目录，不需要管理员权限。向导界面为英文，可在最后一步启动桌宠。开始菜单的“宿傩桌宠”也可启动，安装时可选创建桌面快捷方式。不要单独移动 SukunaPet.exe，它需要旁边的 `_internal` 目录。

当前源码已加入 #23 的 V5 头颈与眼动、#24 的整体点击回弹和连点接续，以及 #25 的持续跳动与模式切换；现有 #17 安装器仍为首版眼动，V5 安装器待后续交付票更新。

首次启动角色静止。单击可见角色，每次头颈与眼睛共同推进一个视线阶段，到达后停留；连续点击可接续循环。视线 2 停留后，再点一次进入视线 3 并眨眼；头部在眨眼期间连续运动。按住角色拖动，松开不算点击。透明留白可点击下方应用。右键角色选择：

- **点击跳动**：单击逐阶段推进。
- **持续跳动**：每阶段动作、眨眼及回弹完成后约停 450ms，再自动推进并回弹，仍接受点击。
- **调整大小**：选择 188px、271px 或 320px（最大）高度，宽度等比缩放；默认 320px，选择后立即生效并在下次启动恢复。
- **退出**：结束程序。

每次点击同时触发 220ms 的整体回弹，110ms 达到宽 110%、高 85% 后恢复；头眼保持目标阶段。连点从当前动作继续前进并重启一次回弹，幅度不叠加、不排队；拖动或手势中断不触发回弹。

源码版 #26 支持将人物轮廓拖到屏幕工作区任意边或角，偏头和回弹时持续贴齐边缘，人物完整可见；透明留白可以越过屏幕边界。切换三档大小仍保留所贴边。往内拖离一条边即可解除该方向的贴边，移到普通位置后播放不移动窗口；重启不恢复贴边或位置。真实单屏操作记录见 [#26 验证记录](verification/issue-26/README.md)。

选择模式后立即记住，下次启动恢复。切回点击模式时立即停止后续自动推进，当前阶段、眨眼及回弹自然完成后停住；等待中切换不额外推进。三档尺寸指完整运动画布高度，留白用于容纳偏头和最强回弹，当前透明处仍可操作下方应用。持续模式途中点击会替换当前目标、重启回弹，并从这次动作完成后重新等待，不积压后续动作。

卸载前从右键菜单退出，再通过 Windows“设置 → 应用 → 已安装的应用”中的“宿傩桌宠”，或开始菜单“卸载宿傩桌宠”移除。卸载移除程序与快捷方式，保留模式偏好，重装后可以恢复。偏好文件通常位于 `%LOCALAPPDATA%\skip-pet\sukuna-pet\mode.json`，若要完全重置，可退出后手动删除此文件。

程序无需安装 Python，无需参考程序、原视频、联网或宿主配置。不包含开机启动或任务联动。

素材来源在 `_internal\sukuna_pet\assets\provenance.json`；随包第三方许可位于 `THIRD-PARTY-LICENSES`。本构建未做代码签名。实际验证条件与尚未完成的验收见随源码的 `docs/verification/issue-17/README.md`。
