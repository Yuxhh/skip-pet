# 宿傩桌宠 0.3.0

适用于 Windows 10 1809 及更新版本、Windows 11 x64。双击 Setup.exe，按向导安装；默认安装到当前用户目录，不需要管理员权限。向导界面为英文，可在最后一步启动桌宠。开始菜单的“宿傩桌宠”也可启动，安装时可选创建桌面快捷方式。不要单独移动 SukunaPet.exe，它需要旁边的 `_internal` 目录。

本安装版包含 V5 头颈与眼动、整体点击回弹、持续跳动节奏、动态透明命中和贴边，以及 DeepSeek 接入、任务联动和状态气泡。安装目录的“验收说明.md”列出实际验证范围与待验条件。

首次启动角色静止。单击可见角色，每次头颈与眼睛共同推进一个视线阶段，到达后停留；连续点击可接续循环。视线 2 停留后，再点一次进入视线 3 并眨眼；头部在眨眼期间连续运动。按住角色拖动，松开不算点击。透明留白可点击下方应用。右键角色选择：

- **点击跳动**：单击逐阶段推进。
- **持续跳动**：每阶段动作、眨眼及回弹完成后约停 450ms，再自动推进并回弹，仍接受点击。
- **任务联动**：已确认的任务仍有助手执行时持续跳动，只剩等人操作时停止自动跳动；空闲可手动点击推进。
- **启用/关闭 DeepSeek 接入**：管理状态监测和随包插件，独立于播放模式。
- **调整大小**：选择 188px、271px 或 320px（最大）高度，宽度等比缩放；默认 320px，选择后立即生效并在下次启动恢复。
- **退出**：结束程序。

每次点击同时触发 220ms 的整体回弹，110ms 达到宽 110%、高 85% 后恢复；头眼保持目标阶段。连点从当前动作继续前进并重启一次回弹，幅度不叠加、不排队；拖动或手势中断不触发回弹。

本版支持将人物轮廓拖到屏幕工作区任意边或角，偏头和回弹时持续贴齐边缘，人物完整可见；透明留白可以越过屏幕边界。切换三档大小仍保留所贴边。往内拖离一条边即可解除该方向的贴边，移到普通位置后播放不移动窗口；重启不恢复贴边或位置。真实单屏操作记录见 [#26 验证记录](verification/issue-26/README.md)。

本版在跨屏拖动时按鼠标位置选择屏幕，桌面间隙使用最近屏幕，并按各屏工作区限制可见人物。切屏更新画面与鼠标轮廓；任务栏、屏幕布局或连接变化后重新检查可见性。当前仅有单屏 DPR 1.0 运行环境，真实双屏、负坐标屏和混合 DPI 操作仍待安装版硬件验收；屏幕夹具与合成 DPR 自动化不能替代这些项目，详见 [#27 验证与待验清单](verification/issue-27/README.md)。

选择模式或大小后立即记住，下次启动恢复。切回点击模式时立即停止后续自动推进，当前阶段、眨眼及回弹自然完成后停住；等待中切换不额外推进。三档尺寸指完整运动画布高度，留白用于容纳偏头和最强回弹，当前透明处仍可操作下方应用。持续模式途中点击会替换当前目标、重启回弹，并从这次动作完成后重新等待，不积压后续动作。

卸载前从右键菜单退出，再通过 Windows“设置 → 应用 → 已安装的应用”中的“宿傩桌宠”，或开始菜单“卸载宿傩桌宠”移除。卸载移除程序与快捷方式，保留模式和大小偏好，重装后可以恢复。偏好文件通常位于 `%LOCALAPPDATA%\skip-pet\sukuna-pet\mode.json`，若要完全重置，可退出后手动删除此文件。

程序无需安装 Python、参考程序或原视频。单独使用角色动作无需联网。不包含开机启动。

## DeepSeek 接入与气泡

先从日常桌面入口安装并打开 DeepSeek Harness，再在角色右键菜单选择“启用 DeepSeek 接入”。预检列出实际 desktop profile、随包插件、Node/pnpm 和将修改的配置；确认后后台安装，成功才保存启用状态。接入维护需要可用的 Node.js 和 pnpm（或独立 pnpm.exe）；Setup 自带零依赖桥插件，不附带这些外部工具，也不会创建新的宿主 profile 或替换日常宿主。失败时按提示补齐已有工具环境后重试。

首次安装或升级刷新后，正常重开 DeepSeek Harness 使插件生效。右键选择“任务联动”即可按任务跳动；选择点击或持续跳动时，已启用的监测和气泡继续工作。退出一个桌宠只释放该实例占用，不自动关闭共享接入。

气泡使用一句话显示已确认的运行、等批准或等回答；运行和等待常驻，完成、失败、中断的结束提示最多展示 8 秒。并行子代理归入所属一轮任务，同轮仍执行且等人时同时保留两类信息。短句缩小，长句在可用宽度内换行增高，文字变短后收缩；透明圆角气泡不拦截鼠标，随角色移动并避让工作区。

查不清的状态无文字；刚启动或重连时可能短暂没有气泡。连续 3 秒健康计数不增长确认失联后，旧文字立即隐藏，之前已确认运行时最多再跳动 5 秒。恢复先确认新鲜健康和当前事实，不补播历史完成提示。

本版适配已验证的 DeepSeek Harness 0.2.1-rc.2，随包桥插件 0.3.2、协议 schema 1。普通提问/审批、已确认归属的本地子代理和单一等待重载已有日常宿主证据；嵌套外层执行、跨轮多个 continued 问题和其他 provider 归属仍可能未知。宿主升级后需重新核对适配。

## 更新、移除与故障恢复

退出桌宠后运行新版 Setup，保留合法的模式、大小和接入偏好。已启用接入的桌宠启动时在后台刷新本项目拥有的旧路径；按提示正常重开宿主。用户自行指定的 registry 依赖不会被替换。

接入异常时，先核对安装目录及日常 desktop profile，正常重开宿主和桌宠；仍失败可关闭后重新启用接入。诊断通常在 `%LOCALAPPDATA%\sukuna-pet\maintenance.log`，卸载诊断在同目录 `uninstall-cleanup.log`。profile 内 `sukuna-bridge-backup-*` 保留修改前配置；只按差异修复本项目条目，不整份覆盖之后的用户修改。

关闭接入或卸载只移除本项目拥有且无其他实例使用的插件；其他实例仍使用时保留共享接入。卸载时若插件位于即将删除的安装目录，会先保存独立副本；最后一个使用实例关闭接入时再移除。失败会保留诊断，卸载清理失败会保留程序文件，修复后重试。多个 profile 部分成功时，以逐项结果为准。

素材来源在 `_internal\sukuna_pet\assets\provenance.json`；随包第三方许可位于 `THIRD-PARTY-LICENSES`，桥插件 MIT 许可在 `_internal\sukuna_pet\integrations\dsh-bridge\LICENSE`。本构建未做代码签名。当前验收进展见随源码的 `docs/verification/issue-42/README.md`。
