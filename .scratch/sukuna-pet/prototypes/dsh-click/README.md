双击 `index.html`，或访问当前本机预览 `http://127.0.0.1:8775/`。HTML 内嵌全部图片，状态只在内存。点击角色或主按钮、连续点三次、快速点五下、重复演示均可体验。可勾选四分之一速或静看最大压扁姿态；正常速度默认开启。眼睛可单独关闭以聚焦形变。

## 采用的发行物事实

来源为用户指定 `D:/dsh-pet/app/dsh-pet-standalone-webm-chat.exe`，SHA-256 `687255faea034bd0e672a870da732650dbbd5b9aae050586e143ac1e55c50407`。REA 只读识别它为 x86_64 PE；随后对 PyInstaller 归档中的原 Python 3.11 字节码做只读解析与反汇编，未执行提取出来的 pet 模块。

普通窗口与 Overlay/sprite 两条普通点击绘制路径一致：

```text
p = clamp(elapsed / 220ms, 0, 1)
pulse = sin(pi * p)
sx = 1 + .10 * pulse
sy = 1 - .15 * pulse
w = round(original_width * sx)
h = round(original_height * sy)
x = round((canvas_width - w) / 2)
y = canvas_bottom - h
```

松开鼠标的普通非拖动点击触发；110ms 时宽 110%、高 85%，220ms 时恢复。整帧水平居中、绘制底边锚定，透明留白也参与锚定。本预览应用于宿傩 1419×1108 全帧，未改按可见人体 bbox 定锚。连点重新从进度 0 播放同一脉冲，不累加，也不自行改成平滑追赶。

几何反馈本身没有额外上下平移、旋转、晃头或单独头部形变。正常点击还会同时切换参考角色的点击视频；该视频动作不是这套 Q 弹几何参数的一部分。本页只复现通用 Q 弹，不冒称复刻了参考程序当前所有特效或原角色动画。

定位与完整证据见 `../../research/dsh-click-20261024/findings.md`、`click-evidence.txt`、`click-evidence.json` 和复现脚本。关键原代码对象位置为 `pet.window._squash_geometry` (window.py:200)、duration (window.py:677)、`_start_squash` (window.py:2388)、`PetSprite._squashed_rect` (pet_sprite.py:1126) 与 `SQUASH_DURATION_MS` (pet_sprite.py:44)。这些原文件/行号来自代码对象，不是恢复的原始源文件。
