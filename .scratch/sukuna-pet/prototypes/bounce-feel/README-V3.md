# 视线阶段原型 V3

双击 `index.html` 即可运行，图片全部内嵌；本机预览仍为 `http://127.0.0.1:8768/`。

## 真人纠正后的要求

- 一次点击只播放到下一阶段的短动作；停止点击后保持当前阶段，再点才继续，连续点击才能循环。
- 阶段的核心特征是眼睛的转动方向，视线顺序按原视频复刻，不能以身体位置取代。
- 原视频提取边缘过于粗糙，用户已允许参考造型重绘。
- 视线 2 结束的瞬间先眨一次，闭眼时直接跳到终点视线，再睁开保持；该段不缓慢转眼，停留时不重复眨。

前述要求取代 V1 的“单击整轮/连点重播/自动回起点”，也纠正了中间 V2 只按身体摆动分阶段的方向。V1 保留在历史提交 `e800cdd246833a27f5b797da6d19b616789e8258`。旧 README、旧 OBSERVATIONS、旧 manifest、旧 build_demo.py 与旧截图只作历史证据，不能作为 V3 规格或验收结论。

## 当前候选

从原片眼部对照图读取变化，先用 f022、f035、f046、f056 作为四个视线停留点，f063 接回周期起点。普通阶段按候选 24fps 时间推进后保持；视线 2 结束时自动眨眼并直接到终点，不等额外点击；两次点击后自动眨眼收尾，下一次点击接回起点，继续点击才进入下一轮。不是预设“左上右下”循环。

眼球位移来自对压缩原片的人工读图近似。原片部分帧模糊且眼皮开合变化明显，**精确眼动轨迹和阶段分界仍待对照确认**，不能声称像素级复刻。右侧展示同一进度的原片眼睛和重绘眼睛。源证据为项目 research/diagnostics/eye-phase-contact.jpg 与 eye-detail-contact.jpg。

默认关闭身体辅助运动，便于单独判断眼球。可以打开辅助摆动，也可以切回旧版提取对照。浅、深、棋盘背景均可检查新轮廓。

内置 imagegen 先生成完整透明半身，再生成去掉虹膜/瞳孔但保留眼白和眼框的底图。原始 PNG 复制到 `assets/`，没有再抠图。Canvas 在眼白路径内绘制可动虹膜和瞳孔；视线 2 结束的瞬间触发一次 240ms 闭合/睁开，在 120ms 闭合点直接跳到终点视线，保持时不会重新触发。提示词见 `REDRAW-PROMPTS.md`。

动作途中再次点击会继续更新前方目标，不回首帧；极快点击采用覆盖前方目标、最多向前走一轮的候选行为，不积压多轮。此细节及自动模式点击优先级仍待反馈。三模式和任务状态原有规则保留为折叠对照。
