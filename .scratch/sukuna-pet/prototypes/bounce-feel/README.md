# 弹跳手感交互原型（一次性，待真人反馈）

回答 [点击弹跳的手感与桌面交互怎样验收](https://github.com/xyd-0811/skip-pet/issues/5)。本目录不属于成品桌宠。双击 `index.html`，无需安装、联网或服务；所有图片内嵌在这个 HTML 中。原视频没有嵌入或上传。

## 怎么看

1. 点击跳动：先观察静止，点一下，等其回到 f000；再试中途点击和快速连点后停止。
2. 持续跳动：至少观察三个周期接缝，然后点击，再切回点击跳动，观察收尾。
3. 任务联动：让 Codex 两项任务分别运行、等待、完成，再试 DeepSeek 任务，验证任一运行则持续跳动。断线按钮模拟明确断线后的 10 秒宽限；恢复读取当前最新选择。
4. 两个选段均为 41 帧。左侧透明角色与右侧原片裁切同步，右侧保留源背景作为姿态及时序依据。短过渡只作用于接点、重跳和收尾；可切换“原帧硬接对照”查看处理差别。
5. 拖动与点击用 6 CSS px 作为候选分界。把角色放到按钮上方，点透明角落检查页面内 alpha 命中；可取消穿透作对照。角色限制在预览区域内。角色右键提供三模式和退出预览；重置可恢复。

页面下方提供逐步场景按钮，每个场景从已知状态开始。所有状态仅在内存中，关闭页面后不记忆。正式产品的模式记忆已经在状态规则票中确认，本次不重复验证持久化。

## 真实素材与候选处理

- 使用原片 f000，以及 f016–f102 共 87 张运动帧；按 24fps 的原帧顺序播放。不用通用弹簧代替原视频。
- f022–f062、f032–f072 都是 41 帧 / 1.7083 秒的候选，不是精确周期已锁定；起止点须由真人确认。
- f000、f036、f064 的静态蒙版沿用素材决策原型。其他帧用近似原姿态参考蒙版和反向块匹配产生粗轮廓，所有帧裁片 y380 以下透明。源 RGB 在缩小前逐像素保留；显示时缩小为 288×225，并压入无损透明 WebP 图集。原片对照图集用有损 WebP，仅供观察节奏。
- 运动轮廓未逐帧人工描绘，可能残留背景、缺失发丝或闪边。原视频既有的上缘截断和运动模糊保留，不能视为修复。
- 短过渡候选：点击时截取当前画面，在 120ms 内过渡到从选段起点即时播放的新动作；不排队、不忽略。重复点击覆盖过渡快照，不积累图层或待播放周期。
- 连续播放：每周期尾部 120ms 与首帧混合，下周期接着播放。无需停止时不插入静止周期。停止时完成当前周期，再用 160ms 与 f000 混合；恢复连续跳动时从当前画面过渡起跳。
- 这些混合可能产生双影；不是补帧或已证明的姿态连续。短过渡、候选周期、6px 拖动阈值、角色大小和屏幕边界行为均未通过真人验收。
