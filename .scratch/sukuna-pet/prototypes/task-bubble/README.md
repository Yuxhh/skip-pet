# 任务状态气泡 · 可丢弃原型

对应[桌宠上方的任务状态气泡如何显示](https://github.com/xyd-0811/skip-pet/issues/36)，隶属[宿傩桌宠双宿主任务状态气泡规划地图](https://github.com/xyd-0811/skip-pet/issues/30)。2026-10-25，待真人选择；本轮不实现生产气泡。

双击 `index.html` 即可运行，图片全部内嵌，无网络依赖、宿主连接或持久化。也可以在本目录执行 `python -m http.server 8786 --bind 127.0.0.1`，浏览器打开 `http://127.0.0.1:8786/?variant=A`。

三个结构候选：A 一句话；B 在一个气泡内按宿主分行；C 数量和状态在上、角色台词在下。底部箭头和键盘左右键切换，URL 参数 `variant=A|B|C` 保留方案。没有任务列表、气泡点击操作或任务控制。

所有情景均为示例。涵盖运行、审批／回答等待、两端并发、同一轮内部执行与待审批并存、部分未知、全部未知、完成、失败、中断、一个结束其他仍运行、确认断线和另一端继续运行。状态语义以[已确认的状态决策](https://github.com/xyd-0811/skip-pet/issues/33#issuecomment-6398138655)为准。

**待真人决定的候选**：最终文案及口吻强度；气泡结构；运行／等待常驻或变化后显示 6 秒；结束提示 4／8／12 秒；完成与并发事件如何占用同一个气泡；头顶空间不足时下移、必要时侧移；能力信息放在未来设置／接入说明而非持续占用任务气泡。控件默认值不代表用户接受。

未知不显示文字；确认断线立即隐藏该端文字，跳动最多宽限 10 秒。仅显示已知部分时明确计数范围。同轮待审批不是额外任务。现有三种动作模式与气泡显示策略分开：只选择气泡策略不改变任务有效期或执行状态。

角色运动帧通过 `build_preview.py` 从当前仓库 `PetApplication` 和 `CharacterRenderer` 采样，每 20ms 一帧；不改生产代码、设置或安装版。网页单击播放采样阶段，拖动不触发点击；采样片段不验证原生连续点击中途改目标的所有时序。网页双屏及混合 DPI 仅验证逻辑坐标下的定位候选，不能当作 Windows 多屏原生验收。

`inspect.cjs` 是本次临时浏览器检查记录脚本，`observations.json` 和 `preview-*.png` 保存代理观察。页面错误、隐藏时机、断线宽限、单击拖动和 15 组尺寸／位置样例通过网页检查，不等于真人认可。重建：仓库虚拟环境 Python 执行本目录 `build_preview.py`（需要项目 PySide6）；检查脚本使用本机 Chrome 和已安装的 Playwright。

本票保持开放，收到真人反馈后才写 resolution；本原型未解决实际双宿主接入。
