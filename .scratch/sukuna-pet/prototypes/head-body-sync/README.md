# 头身联动与眼动同步：独立候选原型

2026-10-24，待真人视觉反馈。对应 [怎样的头身跳动与眼动同步效果符合参考视频](https://github.com/xyd-0811/skip-pet/issues/20)，属于 [宿傩头身联动与眼动同步规划地图](https://github.com/xyd-0811/skip-pet/issues/19)。不是正式接入或安装版。

直接双击 `index.html` 即可。图片全部内嵌，不联网、不保存偏好。当前本机入口为 `http://127.0.0.1:8773/`。`preview.template.html` 是可读源码；运行 `python build_preview.py` 可用同目录图片重建单文件，需 Pillow。`frames.npy` 只是本机解码缓存，不属于原型快照。

## 本原型回答的问题

已认可重绘半身通过整体变换或头身相对形变，能否接近参考视频中需要的起伏、倾斜和配合感？阶段停留、第三段眨眼、快速连点和循环接点是否可接受？

候选 A 只做整体变换；候选 B 使用同一整体轨迹，再对头部相对领口做偏转、位移和小幅缩放。连续网格从头部过渡到衣领，没有把头像剪成另一张独立贴片。还可切回仅眼动基线、调 50%–150% 幅度、换背景。切换不会重置进度。所有候选参数都待反馈，不恢复此前删除的身体方案。

## 原片观察与拟合边界

唯一视频来源仍为地图所指原文件；全片 24fps。本次只解码读取 f022–f063，以 `(0,415)-(576,865)` 裁切并缩小成 `source-sheet.jpg`。没有读取或改动参考程序。原文件 SHA-256 复查为 `3982a4a6602b4c7670696ee264829cc105f9731176fedba56137342f32bca083`，与原研究一致。

直接看 `source-poses-grid.jpg`：

- f022 到 f035，脸部明显下移、缩小并倾斜，领口圆标随之变化；胸前 XEN 却留在近似的下部位置。选胸前下部作候选锚点来源于这个观察，不代表真实物理支点已测定。
- 同时，上方横栏杆从上沿之外进入可见画面，栏杆间距和倾斜也变化。画面运动与人物运动混在一起，不能把屏幕位移全部归入角色。没有从这些画面推算唯一的相机运动。
- f046 附近头部回升；f051 有原研究已指出的模糊和低头趋势；f056 的头部倾斜与 f046 不同，随后 f063 接近较高起姿。候选保留相位顺序，未合成源片模糊。
- 脸、领口与胸前圆标的相对位置变化支持比较头身相对运动；其三维原因无法从这几帧唯一分离。因此 B 是手工拟合的视觉假设，不是人体跟踪结果。

`poses` 数组是对多个可见关键姿态的手工拟合：位移、倾斜、缩放以及头部相对运动；参数不是自动测量值，也没有读取 `face-proxy.csv` 生成身体轨迹。静态重绘无法复现源片转头、自遮挡、衣领轮廓变化或动态模糊。小幅网格拉伸、接点与幅度均需真人判断。

## 时序与刻意展示的取舍

- 沿用视线边界 `[0,13,24,34,41]`、原眼球轨迹和角色右眼第二阶段额外左移。普通阶段按 72 源进度单位/秒，即固定 3×。
- 点击逐阶段推进；第二阶段结束先停住，第三次点击触发一次 240ms 眨眼。眼球在 120ms 完全闭合时直接到终点；身体在完整 240ms 内连续走完相应动作，睁眼时一起抵达。
- 原片侧按身体进度选帧定位。普通动作对应压缩到 1/3 的源时间；第三段改为适配眨眼的时序。专用“1× 单独播放”只播放原片并冻结候选，避免原速和候选速度混称同步。
- 自动循环为了共同在睁眼时抵达终点，等完整眨眼后才回程。一轮理论约 `24/72 + .240 + 7/72 = .671` 秒，比历史仅眼动循环约长 120ms。这是需要真人接受的候选变化，不冒称旧循环时序原封不动。
- 连点仍覆盖前进目标，不新增队列；眼球沿用先提交待定闭眼换位的语义。身体从当前连续相位追向新目标，避免把眼球跳位直接变成跳身。因此眨眼中再点会出现短暂不同相，专门提供了闭合前和睁开时再点的场景。该场景是本次预览要决定的取舍，不认为已验收。
- 从自动切回点击时完成正在播放的阶段。第三段闭合或睁开中切回均停在第三段终点，不多走回程。
- 源末 f063 与 f022 不是逐像素相同姿态。候选将最后部分平滑接回自己的起点，循环连续来自拟合曲线，不能据此宣称源素材已无缝。

## 代理操作观察

通过浏览器实际按钮检查：第一次点击停在视线 1、身体/眼动均 13；第二次停在视线 2、均 24、眨眼 0；第三次停在视线 3、均 34、眨眼 1。快速点五下最终停在下一轮视线 1、均 13、完成一轮，无持续播放队列。持续模式跨多个周期；切回点击模式后停在当前阶段终点。

另对原型纯模型按 1ms 步长采样，记录 `model-observations.json`，用于观察眼球跳位与身体相位是否分开。普通三次点击、快速五次点击、持续循环、自动眨眼中点击、自动睁眼中切回五组场景，最大身体相位单步增量分别约 .072、.115、.072、.144、.072。未出现眼球那样的瞬间 10 单位身体相位跳位；这不能证明人体运动自然或所有触发时刻都无问题。

浏览器可见外观截图与状态记录只是代理观察；没有真人确认前不关闭决策票、不把候选参数写入已确认术语、不推进正式接入。原生渲染方案由后续票继续验证。
