# 头部伸缩与眼动同步 · V2 独立原型

2026-10-24，等待真人视觉反馈。对应 [怎样的头部伸缩与眼动同步效果符合参考视频](https://github.com/xyd-0811/skip-pet/issues/20)。

## 最新真人纠正优先

用户原话：「错了，我想要的效果主要是像这个视频里头有伸缩的效果，身体几乎不动」。此前 V1 的整体平移、倾斜和缩放方向被否定；不能把 V1 作为已认可动作。历史 V1 提交 `5d1e0c0c52be92a99a23423f4252f5b064038969` 仅用于追溯。

本版用固定肩胸与衣领，单独使头发和脸一起收缩、伸展。头部靠近领口的连接位置固定，纵向收放较明显，横向少量变化。前衣领固定遮挡连接处；不再对整张半身做位移、旋转或缩放。默认幅度 100%，可调 50%–150%，仅保留伸缩候选和仅眼动基线。

当前头部高度关键候选：起点 100%、视线 1 终点 84%、视线 2 终点 93%、第三段途中最低 76%、视线 3 终点 94%，回程略伸展至 102.5% 后回到起点。它们是便于真人判断的手工近似，不是源片人体测量或已获认可的参数。

## 参考与时序

原片仍使用地图所指的同一视频，未修改原文件；SHA-256 为 `3982a4a6602b4c7670696ee264829cc105f9731176fedba56137342f32bca083`。本轮重新解码并查看 f022/f030/f035/f042/f046/f049/f051/f053/f056/f060/f063 的头部和领口；见 `head-extension-source.jpg`。原片存在背景运动和模糊，未声称分离了真实相机轨迹。新候选以用户明确的视觉意图为准。

沿用前版原型的视线阶段、眼球轨迹、第二阶段角色右眼左移、普通 3× 眼动、240ms 眨眼和点击目标覆盖语义。前两阶段分别停留；第三次点击才触发眨眼，眼球于 120ms 完全闭合时换位，头部伸缩连续走完 240ms，在睁眼时到位。自动循环候选仍约 671ms，眨眼中连点仍可能有头部追赶眼动的短暂不同相；这两项候选时序未获真人接受，本轮没有额外改变它们。

原片侧按头部进度定位，普通阶段源时长压缩至 1/3，第三段适配眨眼；另有冻结候选、单独播放 1× 源片的入口。最后几帧平滑接回候选起姿，不认为源片本身天然无缝。
